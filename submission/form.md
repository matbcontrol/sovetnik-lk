## 1. Что сделано за 48 часов и что нет

Советник для кабинета Softline. Эффективно: у организаций советы в 3,3 раза точнее базового способа организаторов (их скрипт: 14,9 % против 4,5 %; у частных лиц прибавки нет). Дёшево: 0,45 ₽ за визит — около 4 000 ₽ в месяц при 300 визитах в день, нейросеть на запрос не вызывается. Удобно: встраивается одним тегом, замены и новинки готовит сам, пилот «тест против контроля» — рост кликов виден за две недели.
Проверить: python -m recsys.eval.proof — 14,90 %, отпечаток ответов совпадает со стендом (2e743581…).
Стенд https://matbcontrol.github.io/sovetnik-lk/ — там же макет кабинета (cabinet.html) и встраивание (embed.html).

Работает и показано в видео:
- Блок из трёх частей: «Пора продлить», до трёх личных советов с объяснением и схемой «почему», строка «Часто докупают»; клиенту без истории — популярное для его типа с пометкой «не личный совет».
- Показ блока: обоснованный совет получают 91 % организаций с доступом в кабинет — сейчас блок показан в 55,6 % визитов (сравнение не строгое). У частных лиц — 55 %, и только за счёт слабого «если ещё нет…».
- Precision@3 по скрипту организаторов (evaluate и hit_split из baseline.py), датасет v5, все клиенты групп A и B (B — холодный старт): организации 14,9 % / 17,7 % против 3,75–4,53 % / 4,54–5,22 %; частные лица 21,9 % / 24,0 % против 15,2–20,0 % / 14,7–20,0 % — прибавка в пределах погрешности. Перевес не случаен: +10,4 п.п. к лучшему базовому (95 % интервал 8,2–12,7), у 100 организаций наш набор угадал больше, у 12 меньше. Fill Rate 100 % (у совместных покупок 92,3 % и 87,2 %).
- Устойчивость: на пяти зёрнах 14,6–15,0 %; на ранних разрезах — 13,7–13,8 % против 4,3–5,1 %.
- Симуляция ИИ-клиентов вслепую (337 клиентов): организации нажали бы на наш блок в 41 % случаев против 17 %, купили бы — 33 % против 9 %; «купил бы» сбылось в 50 % против 7 %. У частных лиц перевеса нет.
- Доля вариантов среди попаданий (по product_group): у организаций 46,7 %, у совместных покупок 12,2 %, у популярности 0 %. Только по новым продуктам — 72 попадания против 36 и 34 (7,9 % против 4,0 % и 3,75 %); по нашей строгой мерке, где редакция и продление — тот же продукт, новых 23, как у популярности. Без продлений купленного — 7,8 % против 4,2 %.
- Проверка пар «купил А — советовать ли Б». Статистика не отличает «нужно» от «и так есть»: блок советовал к антивирусу Windows, а КриптоПро CSP стоял личным советом у 87 % организаций. Теперь 15 241 пара заранее размечена по правилам менеджера: нужно, комплект, уже есть, то же самое, не связано. В блоке у 302 организаций 723 личных совета (сбылось 6,5 % против 7,0 % без проверки пар); самый частый товар — у 26 % клиентов вместо 87 %; «комплекты» не сбылись ни разу (0 из 135).
- Граф открытых источников на 13 503 товара: версии, дополнения, аналоги, проверенные пары, совместимость. Товару без своей истории знания каталога дают 13,1 % против 3,9 % без них.
- Замена снятых с продажи зарубежных программ готова для 2 865 из 4 506: прямой аналог (101) — сразу, по классу — после решения менеджера (сейчас заявка ждёт 1–2 дня).
- Агент каталога работает, когда товар заводят в магазин: пишет паспорт, выбирает класс и связи, критик снимает неподтверждённые. На 24 спрятанных товарах (облегчённая Gemini Flash-Lite): базовый продукт дополнения 6 из 8, класс 21 из 24 (один код — 20), критик снял 8 из 31 связи. На deepseek-v4-pro: дополнения 3 из 8, класс 21 из 24, 4,2 вызова и 1,42 ₽ на товар.
- Встраивание: виджет (один тег) или POST /api/advice — ответ в формате нынешнего блока за миллисекунды. Журнал показов, переходов и «Запросить счёт» с группой пилота (действия посетителей, не прогноз продаж).

Сделано частично:
- Первую разметку пар сделал ИИ-ассистент. Порог 85 % одинаковых решений не прошла ни одна модель по API: gemini-3.6-flash — 77 %, deepseek-v4-pro с рассуждением — 81 %; вторая разметка вслепую — 86 %. Поэтому пары размечают две модели: обе против — вердикт сразу (верно 68 из 70), иначе — менеджеру.
- Личный совет по покупке есть у 60 % товаров в продаже, но «нужно» — лишь у 936, у остальных 4 183 — один «комплект». Подбор и замены по классу ждут менеджера — 557 строк.
- У частных лиц один комплект (Kaspersky Standard) видят 66 % клиентов; доля сбывшихся советов у них 15,4 % против 18,1 % без проверки пар.
- Агент закрывает дыры (deepseek-v4-pro): из 125 товаров без совета клиентам сразу ушли 5 связей, 25 ждут менеджера; «спрятали — вернул» на 26 чистых товарах — 1 из 54 «нужно» (с рассуждением — 4).

Не сделано — включить пилот в кабинете Softline: готовы виджет, POST /api/advice, образ Docker, разбиение на тест и контроль и отчёт с 95 % интервалом; при 300 показах в сутки две недели покажут рост кликабельности в 1,5 раза, для конверсии в счёт нужно около четырёх недель. Не прогнана модель, размещённая в России (её цена — в расчёте).

## 2. Подход и архитектура

ИИ работает заранее, а не на каждом клике — схема на стенде, панель «Как это работает».

Заранее — раз в сутки и при новом товаре:
- Граф знаний из открытых источников (фид, страницы магазина, реестр российского ПО, таблица АРПП): 13 503 товара; связи — продление, редакция, дополнение, совместимость, аналог.
- Проверка пар по правилам менеджера: нужно, комплект, уже есть, то же самое, не связано. Новые пары проверяют две модели: «обе против» — сразу, остальное — менеджеру.
- Модель ранжирования: градиентный бустинг, 42 признака, учится на обезличенных продажах организаторов, сдвинутых в прошлое; пересчёт — около 2 минут процессора.
- ИИ-агент для новых товаров: паспорт, класс, связи; критик оставляет только связи с дословной цитатой; 4,2 вызова и 1,42 ₽ на товар.

В визите — без нейросети, меньше миллисекунды: покупки и лицензии → кандидаты из графа и истории → запреты (тип клиента, платформа, дубль купленного, снято с продажи, в разы дороже) → проверка пар → ранжирование → блок (продление, до трёх советов, «Часто докупают») → объяснение из тех же оснований. В браузере или через POST /api/advice — ответ одинаковый.

Измерение: журнал показов, переходов и счетов, тест и контроль, отчёт с 95 % интервалом.

«В 3,3 раза» — модель ранжирования по протоколу у клиентов с историей; для любого клиента кабинета советы считает движок по тому же графу с теми же запретами и проверкой пар.

Как проверяется ответ:
- Вердикты сверены с покупками обучающего периода; утечку проверочного периода в этой сверке нашло ревью, она исправлена.
- Связь агента идёт клиенту, только если критик привёл дословную цитату, код нашёл её в тексте и это не название товара; несуществующие товары и указания внутри карточки код отбрасывает.
- Два запуска ранжирования дают одинаковые числа; движок страницы сверен с Python на 300 клиентах.

- Стенд и виджет: HTML, CSS и JavaScript без библиотек, движок работает и в браузере; сервер на Python — API, журнал, пилот, живой агент.

Модель меняется настройкой, для России — Yandex AI Studio. Стоимость — около 0,45 ₽ на обращение с сервером; главная статья — время менеджера, около 55 минут в день. По API уходили только названия и описания из открытого каталога; данных клиентов модель не получает.
- Баз данных нет: граф и таблицы вердиктов — файлы JSON и CSV. Docker, GitHub Actions: тесты и проверка образа на каждый коммит.
- Хостинг: статическая страница (GitHub Pages); пересчёт раз в сутки — около 2 минут процессора, хватает небольшой ВМ без видеокарты.

## 5. Запуск и поставка

Среда: Python 3.12, 8 ГБ памяти; команды ниже — для Windows, на Linux путь к Python — .venv/bin/python.

Запуск стенда:
uv venv .venv --python 3.12
uv pip install -r requirements.txt --python .venv/Scripts/python.exe
.venv/Scripts/python.exe -m recsys.server
Или Docker: docker build -t sovetnik . && docker run -p 8765:8765 sovetnik (пилот: -e SOVETNIK_CONTROL_SHARE=0.5).
Стенд откроется на http://127.0.0.1:8765. Проверка на данных организаторов: положить dataset_v5.xlsx в data/private/task/, затем python -m recsys.eval.proof (модель обучится заново, счёт — функциями baseline.py, около 95 секунд), python -m recsys.eval.value (все замеры, около 5 минут) и python -m recsys.eval.robust (устойчивость).

Пример запроса: организация; покупки — Kaspersky Endpoint Security Стандартный (11.05.2026, 12 мес.), Adobe Creative Cloud (23.11.2025, 12 мес.), Dr.Web Desktop Security Suite (11.05.2026), Microsoft 365 Personal (30.04.2026); дата 26.11.2026.

Ожидаемый ответ клиенту: 1) следующая ступень — Kaspersky Endpoint Security Расширенный; 2) к вашему продукту — Kaspersky EDR Оптимальный; 3) типовой набор — Traffic Inspector («если ещё нет шлюза…»). Отдельной строкой «Часто докупают» — КриптоПро CSP; под блоком — ещё 1 совет ждёт менеджера.

На стенде это первый пример на вкладке «Клиент». Клиенты из датасета есть только в локальном запуске и в видео: данные нельзя публиковать.
